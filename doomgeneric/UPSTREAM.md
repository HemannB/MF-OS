# Vendored doomgeneric

This directory is based on [ozkl/doomgeneric](https://github.com/ozkl/doomgeneric)
at commit `dcb7a8dbc7a16ce3dda29382ac9aae9d77d21284`.

MF-OS carries local bare-metal adaptations, including the MF-OS platform
backend, freestanding video and main-loop changes, and compatibility fixes for
the shareware WAD. The upstream GPL-2.0 license is preserved in `LICENSE`.
